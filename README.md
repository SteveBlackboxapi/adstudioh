# AdStudioh

Cosmos density × Reve actionability × Ad Age provenance.

A taste/craft/history pack for legendary advertising and design culture — built for Explore-style browsing, reference boards, and agent-readable structured cards.

## What’s in here

| Path | What |
|---|---|
| `best-ads/` | Plug-in catalog (~116 iconic ads) — JSON, CSV, markdown cards + schema |
| `explore/` | Explore product spec, chip config, seed `@` reference boards, HTML prototype |
| `reports/` | Keep-vs-cut teardown of Reve Explore |
| `REFERENCE-PACK.md` | ~1,013 curated research links (ads + design history + hubs) |
| `urls-flat.txt` | Flat URL list from the reference pack |
| `inspiration/` | Notes/assets from competitor demos (e.g. JEV) |

## Explore prototype

```bash
cd explore/prototype
python3 -m http.server 8765
# open http://localhost:8765
```

Feeds: **Style bar** · **Library** · **Boards**. Sticky chips. Detail workspace with credits + dissection stubs.

## Catalog fields (highlights)

Brand, agency, creatives/roles, year, medium, awards, tags, style notes, why iconic, links — plus JEV-inspired `format`, `awareness_primary` / `awareness_mix`, `style_bar`, `source`, `boards`, `dissection`.

## Principles

- Taste lane, not live Meta Ad Library X-Ray
- Dual feed: curated Style bar vs full Library
- Never hide credits / learning behind a wall
- Reference boards encode style DNA
